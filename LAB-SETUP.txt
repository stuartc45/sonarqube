IMPLEMENTATION
CustomFileReader opens a fresh UTF-8 scanner for each operation and closes it
with try-with-resources. Word counts reset on each call. Missing files propagate
to Main for a clear console error. Sentence construction uses StringBuilder.

Main validates its arguments and uses locale-independent case conversion.
Only the tutorial-permitted rules S106 and S1166 are suppressed in Main.
